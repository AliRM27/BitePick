# BitePick

BitePick is organized as a single repository with separate frontend and backend apps.

## Apps

- `expo-app`: Expo / React Native client application
- `backend`: TypeScript Express API with MongoDB

## Getting started

### Frontend

```bash
cd expo-app
npm install
npm start
```

### Backend

```bash
cd backend
npm install
cp .env.example .env
npm run dev
```
